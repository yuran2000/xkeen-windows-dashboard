# Обновление панели с сохранением настроек

Все действия выполняются в папке установленной панели, обычно `C:\xray-dashboard`.
Пароль, подключение к роутеру и ключи заново настраивать не требуется.

## Обновление из панели

1. Открыть `/xkeen` и нажать **«Проверить обновление»** в шапке.
2. Сравнить установленную версию и предложенный выпуск. Для установки нажать **«Обновить до v…»**.
3. Дождаться подтверждения запуска. Панель обновит страницу и откроет **«Что нового?»**.

Одна кнопка проверяет последний стабильный выпуск на GitHub для Git-клона, ZIP с исходниками и готовой portable-установки Windows x64. Панель выбирает подходящий пакет и сохраняет локальные настройки. Описания в «Что нового?» загружаются из GitHub. При временном сбое показывается последняя сохраненная копия. Пока идет обновление, не следует запускать второе обновление или сохранять изменения в панели. Во время ее перезапуска страница может временно потерять связь.

При сбое после замены файлов обновлятор пытается вернуть предыдущую версию и проверить ее запуск. Состояние, журнал и материалы восстановления хранятся в `backups/panel-update` внутри папки установки. При сообщении о прерванной операции или неподтвержденном восстановлении сохранить эту папку перед ручным восстановлением. Журнал может содержать локальные пути.

Если кнопки еще нет, выполнить один переход по типу установки ниже. Git-установка с местными правками или старой историей может потребовать отдельного подтверждаемого восстановления.

## Первое обновление Git-установки без кнопки

1. Запустить `update.bat`. Если панель работает через Планировщик Windows, подтвердить запрос прав администратора. При самостоятельном запуске панели и отсутствии задачи права администратора для перезапуска обычно не нужны.
2. Дождаться строк `[OK] Dashboard running` и `Update complete!`.
3. Обновить страницу панели через **Ctrl+F5**, чтобы загрузить новый интерфейс.

**Первый переход с v1.4.5 или более ранней версии.** Если панель установлена как задача Планировщика,
один раз запустить имеющийся `update.bat` **от имени администратора**. Этот первый запуск выполняет
код старого обновлятора. Если файлы уже обновились, а веб-панель по-прежнему показывает прежнюю
версию, повторно запустить `update.bat` из той же папки и подтвердить запрос Windows.

Сообщение об успехе появляется после того, как новый процесс ответит на порту этого
экземпляра и подтвердит контрольную сумму загруженного кода. Номер в веб-панели
берется из кода, который загрузил работающий процесс. При отмене запроса прав
или ошибке определения задачи обновление прекращается до замены файлов.
При самостоятельном запуске проверяется порт из локальных настроек экземпляра.

Обновлятор сначала сохраняет проверенную резервную копию и проверяет файлы
и зависимости, затем перезапускает панель. При ошибке загрузки работающая панель
не останавливается. Во время обновления не следует сохранять изменения через её веб-интерфейс.

Если обновление не прошло:

- **Ошибка доступа к GitHub или загрузки:** проверить интернет и повторить позже.
- **Запрос подтверждения восстановления:** проверьте сообщение и введите английскую `y` для
  замены с резервной копией. Если старый обновлятор завершился с предложением разового перехода,
  используйте раздел ниже.
- **`Not a git repository`:** установка выполнена из ZIP — нужен раздел «Обновление ZIP-установки».
- **`[FAIL]` или панель не запускается:** сохранить текст ошибки и обратиться в
  [Issues](https://github.com/yuran2000/xkeen-windows-dashboard/issues).
  Пароли, ключи, личные ссылки подписок и файлы настроек прикладывать не нужно.

## Разовый переход со старой версии

Если старый `update.bat` завершился с сообщением о разовом переходе, скачайте новый
запуск восстановления. Он заменит файлы с сохранением настроек и перезапустит панель.

1. Скачать текущие исходники со [страницы проекта](https://github.com/yuran2000/xkeen-windows-dashboard):
   **Code → Download ZIP**, затем распаковать архив.
2. Из папки исходников скопировать в **существующую папку панели** три файла:
   `Recover-Update.bat`, `Recover-Update.ps1` и `Recover-Update.messages.json`.
3. Запустить **`Recover-Update.bat`**. Если Git не может писать в служебные файлы репозитория, подтвердить запрос прав администратора в Windows. На вопрос «Продолжить?» ответить `y`.
4. Дождаться сообщения **«ГОТОВО. Обновленная веб-панель запущена.»**. Скрипт сначала заменит
   файлы, затем перезапустит веб-панель и проверит, что она загрузила обновленный код. Путь к
   резервной копии будет указан в окне. После этого обновить страницу через **Ctrl+F5**.

Дальнейшие обновления выполняются кнопкой в шапке панели.

Если Windows отказала в доступе даже после повышения, сообщение укажет на права или атрибуты файлов `.git`. При отмене запроса прав восстановление останавливается до замены файлов.
Если файлы восстановлены, а запуск веб-панели не подтвержден, сохранить текст ошибки.
После устранения причины перезапуск можно повторить через `update.bat`.

Перед заменой файлов скрипт сохраняет и проверяет резервную копию в `backups/update-…`.
Настройки, ключи и реестр WireGuard-доступов остаются на месте. Если сам код панели
менялся вручную, эти правки сохраняются в резервной копии; после перехода используется
новая версия файлов проекта.

При сообщении о незавершённой операции Git переход останавливается. В этом случае
нужно сохранить ошибку и обратиться за помощью, а не выполнять случайные `reset`/`clean`
или удалять папку `.git`. Резервные копии могут содержать личные данные — их нельзя
публиковать вместе с вопросом.

## Обновление ZIP-установки

Для установки из ZIP файлы `Recover-Update` не нужны.

1. Скачать свежий ZIP исходников на странице проекта через **Code → Download ZIP**
   или выбрать ZIP нужного релиза в **Releases**. Распаковать архив.
2. Остановить панель через `stop.bat` и сохранить копию её папки.
3. Скопировать файлы из нового архива **поверх существующей установки**, с заменой одинаковых файлов.
   Старую папку перед этим не удалять: в ней находятся личные настройки, которых нет в архиве.
4. Запустить `install.bat` для проверки зависимостей. Существующий пароль и настройки сохранятся.
5. Запустить панель обычным способом и обновить страницу через **Ctrl+F5**.

Если после обновления панель не запускается, сохранить ошибку из окна `start.bat`.
Резервная копия позволит вернуться к прежней установке; менять настройки наугад не нужно.

## Обновление portable-сборки

1. Закрыть `xray-dashboard.exe` и сохранить копию текущей папки portable.
2. Распаковать новую portable-сборку целиком в отдельную папку. Если собираете ее
   из исходников, откройте свежие исходники и запустите `portable\build.bat`.
3. Скопировать прежний `config.ini` и используемые локальные настройки и ключи в новую папку.
4. Запустить новый `xray-dashboard.exe` и обновить страницу через **Ctrl+F5**.

## Перезапуск веб-панели

В установке с исходниками выполните из папки панели `.\update.bat -RestartOnly`.
Перезапуск использует уже установленные файлы и проверяет старт на порту этой панели.

## Обновление компонентов роутера

После обновления панели проверить диагностику и баннер отставания структуры.
Если требуется синхронизация, использовать указанную в панели кнопку: она создаёт
резервную копию и проверяет результат. При отсутствии баннера применять структуру
только ради обновления номера не требуется.

Если удалённый доступ к компьютеру идёт через этот же VPN, его перезапуск может
оборвать соединение. Перед таким действием нужен другой способ доступа.

# Обновление панели с сохранением настроек

Все действия выполняются в папке установленной панели, обычно `C:\xray-dashboard`.
Пароль, подключение к роутеру и ключи заново настраивать не требуется.

## Обычное обновление

1. Запустить `update.bat`. При запросе прав администратора подтвердить запуск.
2. Дождаться строк `[OK] Dashboard running` и `Update complete!`.
3. Обновить страницу панели через **Ctrl+F5**, чтобы загрузить новый интерфейс.

Обновлятор сначала сохраняет проверенную резервную копию и проверяет файлы
и зависимости, затем перезапускает панель. При ошибке загрузки работающая панель
не останавливается. Во время обновления не следует сохранять изменения через её веб-интерфейс.

Если обновление не прошло:

- **Ошибка доступа к GitHub или загрузки:** проверить интернет и повторить позже.
- **Сообщение о старой истории, `divergent`, `conflict` или предложение выполнить переход:**
  использовать раздел ниже.
- **`Not a git repository`:** установка выполнена из ZIP — нужен раздел «Обновление ZIP-установки».
- **`[FAIL]` или панель не запускается:** сохранить текст ошибки и обратиться в
  [Issues](https://github.com/yuran2000/xkeen-windows-dashboard/issues).
  Пароли, ключи, личные ссылки подписок и файлы настроек прикладывать не нужно.

## Разовый переход со старой версии

После обслуживания истории проекта старой установке может потребоваться один
переход. Переустанавливать панель и настраивать роутер заново не нужно.

1. Скачать текущие исходники со [страницы проекта](https://github.com/yuran2000/xkeen-windows-dashboard):
   **Code → Download ZIP**, затем распаковать архив.
2. Из папки исходников скопировать в **существующую папку панели** три файла:
   `Recover-Update.bat`, `Recover-Update.ps1` и `Recover-Update.messages.json`.
3. Запустить **`Recover-Update.bat`**. На вопрос «Продолжить?» ответить `y`.
4. Дождаться сообщения **«ГОТОВО»**. Путь к резервной копии будет указан в окне.
5. Запустить обычный **`update.bat`**, дождаться успешного завершения и обновить страницу через **Ctrl+F5**.

Дальнейшие обновления выполняются привычным `update.bat`.

Перед заменой файлов скрипт сохраняет и проверяет резервную копию в `backups/update-…`.
Настройки, ключи и реестр WireGuard-доступов остаются на месте. Если сам код панели
менялся вручную, эти правки сохраняются в резервной копии; после перехода используется
новая версия файлов проекта.

При сообщении о незавершённой операции Git переход останавливается. В этом случае
нужно сохранить ошибку и обратиться за помощью, а не выполнять случайные `reset`/`clean`
или удалять папку `.git`. Резервные копии могут содержать личные данные — их нельзя
публиковать вместе с вопросом.

## Обновление ZIP-установки

Для установки из ZIP файлы `Recover-Update` не нужны.

1. Скачать и распаковать свежий ZIP проекта.
2. Остановить панель через `stop.bat` и сохранить копию её папки.
3. Скопировать файлы из нового архива **поверх существующей установки**, с заменой одинаковых файлов.
   Старую папку перед этим не удалять: в ней находятся личные настройки, которых нет в архиве.
4. Запустить `install.bat` для проверки зависимостей. Существующий пароль и настройки сохранятся.
5. Запустить панель обычным способом и обновить страницу через **Ctrl+F5**.

Если после обновления панель не запускается, сохранить ошибку из окна `start.bat`.
Резервная копия позволит вернуться к прежней установке; менять настройки наугад не нужно.

## Обновление компонентов роутера

После обновления панели проверить диагностику и баннер отставания структуры.
Если требуется синхронизация, использовать указанную в панели кнопку: она создаёт
резервную копию и проверяет результат. При отсутствии баннера применять структуру
только ради обновления номера не требуется.

Если удалённый доступ к компьютеру идёт через этот же VPN, его перезапуск может
оборвать соединение. Перед таким действием нужен другой способ доступа.

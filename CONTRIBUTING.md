# Участие в проекте

Ошибки, вопросы и предложения принимаются через
[Issues](https://github.com/yuran2000/xkeen-windows-dashboard/issues).
В сообщении полезно указать версию панели, модель роутера, версии KeeneticOS/XKeen,
шаги воспроизведения и ожидаемый результат. Секреты и личные настройки не прикладывать.

## Изменения кода

Перед изменениями прочитать [карту архитектуры](docs/ARCHITECTURE.md) и нужный
профильный раздел. Исходники Python — UTF-8/LF; `.bat` и `.ps1` — ASCII/CRLF.
Тексты интерфейса пишутся безлично. Локальные настройки остаются вне Git.

К Pull Request приложить описание поведения и выполненных проверок. Профильная
документация обновляется вместе с кодом. Версию выпуска определяет сопровождающий.

## Проверки

```powershell
.venv\Scripts\python.exe -m py_compile dashboard.py
.venv\Scripts\python.exe tools\check_public.py
.venv\Scripts\python.exe tests\test_update_checkout.py
```

Остальные офлайн-тесты перечислены в [таблице](docs/architecture/10-tests.md).
Они выполняются с подменами SSH/сети, без рабочего роутера. Изменения шаблонов
дополнительно проверяются в браузере на локальном изолированном экземпляре.
Для проверки поведения на рабочем устройстве требуется отдельное согласование.
